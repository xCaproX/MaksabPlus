# خريطة معمارية مشروع مكسب بلس (Maksab Plus Architecture Map)

هذا المجلد يحتوي على التوثيق الهندسي الشامل والخريطة المعمارية لنظام مكسب بلس، ليكون مرجعاً تقنياً حياً ودقيقاً للمطورين والمراجعين. تم تصميم هذه الخريطة لتكون قابلة للإضافة، الحذف، والتعديل مع تطور المشروع.

---

## فهرس ملفات الخريطة المعمارية

| الملف | المحتوى والنطاق |
| :--- | :--- |
| [`OVERVIEW.md`](./OVERVIEW.md) | المعمارية العامة، حزمة التقنيات، هيكل المجلدات، تدفق البيانات العام، ومبادئ التصميم. |
| [`DATABASE.md`](./DATABASE.md) | المخطط الكامل لقاعدة البيانات، الـ 84 هجرة (Migrations)، الجداول، العلاقات، الفهارس، العروض، ودوال RPC. |
| [`BUSINESS_LOGIC.md`](./BUSINESS_LOGIC.md) | محرك المحاسبة، دورة حياة المستندات، حساب تكلفة المخزون (المتوسط المرجح)، الأرصدة، منع السحب على المكشوف، وترتيب الأقفال، والمطابقات. |
| [`FRONTEND_UI.md`](./FRONTEND_UI.md) | معمارية الواجهة، التوجيه (Routing)، إدارة الحالة، المكونات المشتركة، وقواعد الـ RTL و UX. |
| [`SECURITY.md`](./SECURITY.md) | العزل التام للشركات، مصفوفة الصلاحيات التفصيلية، تأمين RPCs، وحجب الأرباح وتكلفة الشراء الحساسة. |

---

## قواعد الحفاظ على الخريطة
1. عند إضافة جدول، هجرة، أو دالة RPC جديدة: يتم توثيقها فوراً في `DATABASE.md` و `BUSINESS_LOGIC.md`.
2. عند تعديل صلاحية أو قاعدة أمان: يتم تحديث `SECURITY.md`.
3. عند إضافة شاشة أو مكون واجهة مشترك: يتم تحديث `FRONTEND_UI.md`.
4. تقارير الإغلاق والتحقق المؤرخة مثل [`performance-closure.md`](../performance-closure.md) و [`security-fixes-report.md`](../security-fixes-report.md) تُحفظ كسجلات تاريخية ثابتة لنتائج وقتها ولا يُعاد تحرير أرقامها بأثر رجعي.
